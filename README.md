# KOL Analytics Studio

独立编写的无需登录达人投放分析网站。内置 28 条完全虚构的合作记录，支持 Excel / CSV 导入、工作表选择、中英文字段识别和手动映射、数据清洗、筛选、候选名单、图表和 Excel 报告导出。

## 本地运行

Node.js 22+，pnpm 10+。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

## 数据与指标

首行为非空、不重复的列标题。至少映射达人名称。支持 10 MB 以内、50,000 行以内的文件。日期请使用 YYYY-MM-DD，费用请预先统一币种。不自动进行汇率换算。完全重复行去重；没有名称的行跳过；无效或负数字段转为缺失，清洗页记录原因。

CPM = 费用 / 曝光 × 1000；CPE = 费用 / 互动量；互动率 = 互动量 / 曝光 × 100%。互动量优先使用显式总互动，否则加总已提供的点赞、评论、分享和收藏。零分母或缺失分子显示 —。汇总指标只使用分子和分母同时有效且分母大于零的记录进行加权计算。缺失互动分项不会自动视为已完整采集。

导出的工作簿包含达人明细、汇总、清洗记录和指标定义；按当前筛选范围导出，候选名单单独导出。所有上传数据仅在浏览器内存中处理，刷新会丢失。没有服务端上传、账户、分析追踪或数据库。

## 部署

Vercel 导入此独立仓库，框架选 Vite，安装 `pnpm install`，构建 `pnpm build`，输出目录 `dist`。无需环境变量。
